Running the show in ShowXpress

The lighting page is where the plan lives. ShowXpress is what plays it on the venue's lights. You never program ShowXpress by hand: you download the show from the page and install it. These steps are for a Mac.

The short version

  1. Set up ShowXpress once (below).
  2. Whenever the plan changes: on a laptop, open the lighting page and click Download for ShowXpress.
  3. Quit ShowXpress, then run the install script from the download (one line in Terminal).
  4. Open ShowXpress, open the Teen Titans timeline, press play.

1. Install ShowXpress (once)

  1. Download it from the ShowXpress download page. On a newer Mac (M1 or later) pick the Apple Silicon build, ShowXpress_Mac_arm.dmg; on an older Intel Mac, the Intel one. Not sure? Apple menu › About This Mac: "Chip: Apple M…" means Apple Silicon.
  2. Double-click the .dmg. A window opens with a ShowXpress folder in it.
  3. Drag that whole ShowXpress folder (not just the app inside it) into Applications. The app needs the files next to it.
  4. Open Applications › ShowXpress › TheLightingController. If the Mac says it can't be opened, go to System Settings › Privacy & Security, scroll down, and click Open Anyway. You only do this once.
  5. In ShowXpress, choose File › New lightshow and name it exactly Teen Titans. Then quit with Cmd + Q.

ShowXpress keeps its shows in your home folder, at ~/TheLightingController/LightShows, not next to the app. File › Open lightshow Folder opens it.

2. Put the show in (every time the plan changes)

  1. On a laptop, open the lighting page and click Download for ShowXpress (next to Download spreadsheet). You get teen-titans-showxpress.zip in Downloads.
  2. Double-click the zip. It makes a folder called teen-titans-showxpress.
  3. Quit ShowXpress (Cmd + Q). If it's open, it saves over the new files when it closes, so the script won't run while it's open.
  4. Open Terminal: Cmd + Space, type Terminal, press Enter.
  5. Paste this and press Enter: 
    bash ~/Downloads/teen-titans-showxpress/install-on-my-mac.sh
    It finishes with Done. (Or type bash and a space, drag install-on-my-mac.sh from the unzipped folder into the window, and press Enter.)

What the script does: replaces the show's scenes, timeline and 3D layout with the new ones, puts the venue's lights in, and the first time, adds the song. Anything you changed by hand inside ShowXpress gets replaced, so make changes on the lighting page instead.

This puts the show in its own "Teen Titans" light show, for watching at home. At Revel, use install.sh instead: it files the show the way Revel does, inside their "default" light show (steps on the Running the lights page).

If an older teen-titans-showxpress folder is still in Downloads, the new one may be called teen-titans-showxpress 2. Delete the old folder before unzipping, or drag the newest install.sh into Terminal instead; the script always installs from its own folder.

3. Watch it

  1. Open ShowXpress. Choose File › Open lightshow › Teen Titans. The title bar should say ShowXpress - Teen Titans.
  2. Check the lights loaded: Editor › Fixtures should show CH1 to CH13.
  3. Go to Live › TimeLine, click the open (folder) icon, and pick Teen Titans. You'll see the song on top and a row of blocks under it.
  4. Unplug the DMX adapter. The 3D view only draws when no adapter is connected.
  5. Open Windows › 3DView.
  6. In the Live screen, top right, click the cube icon so the line under it turns green. That's the 3D output.
  7. Press play. To start partway through, double-click the time ruler above the blocks to move the red marker, then use Play from red marker.

Recording a video of it

ShowXpress can't export video. Press Cmd + Shift + 5, choose Record Selected Portion, and draw around the 3D view. The Mac's recorder doesn't capture the computer's sound, so add the song afterwards (both start at 0:00), or use Download video on the lighting page, which has the song built in.

At the venue

Plug in the DMX adapter, and in the Live screen make sure the DMX output icon (next to the cube) has a green line. Then play the timeline as above.

When something's wrong

The music plays but the 3D view stays dark.Turn on the cube icon in the Live screen (green line). Also check Editor › Steps: if its DMX or 3D buttons are green, turn them off. The Editor overrides Live.
Editor › Fixtures is an empty grid.The show's files aren't in the folder ShowXpress is reading. Run the install script again, then fully quit and reopen ShowXpress. File › Open lightshow Folder shows where it's looking; it should contain Teen Titans.
Teen Titans isn't in the TimeLine's Open list.Make sure Teen Titans is the open show (title bar). Or, in the Open window, press Cmd + Shift + G and paste ~/TheLightingController/LightShows/Teen Titans/Live/TimeLine/timelines/.
The script says ShowXpress is open.Quit it with Cmd + Q (closing the window isn't enough) and run the script again.
Terminal shows quote> and waits.Something you pasted had an unmatched quote or apostrophe. Press Ctrl + C and try again. Nothing ran.
The colours look washed out.Downloads before this fix sent the page's screen colours, which look pastel on Revel's lights. Download again and reinstall: the colours are now saturated the way Quan's own scenes are. The "Colour test" timeline shows each colour before and after, to check them on the real lights.
Lights that should be dark still glow in colour, or nothing dims.Downloads before this fix put brightness on the dimmer, and Quan says Revel's lights only listen to red, green and blue. Download again and reinstall: brightness now goes out on the colour. The "Dimmer test" timeline in the download shows whether the dimmer does anything.
Lights blink off for a moment, or fades snap on instantly.Those were bugs in older downloads. Download again from the page and reinstall.
The lights drift out of time with the music.Quit ShowXpress and reopen it, then play from the start: lights running late after a while fixed themselves that way. Playing a little, stopping and starting again sometimes works too. The timing itself matches the page to the hundredth: each block on the timeline is a few seconds of the show, with every change inside it as a step.
The 3D lights are in the wrong places.Each install puts them back where the stage map has them. To move one, right-click the 3D view › Fixtures setting, but it moves back on the next install, so tell Claude instead and the layout gets fixed for good.

What's in the download

  • scenes/: one scene per timeline block, a few seconds of the show each, with every change as a step. Every step sets all 7 channels of all 12 lights, so nothing is left over from the one before. Brightness is the colour scaled down (Revel's lights ignore the dimmer), and the dimmer is held at full. Colours are saturated for Revel's lights, so they won't match the screen exactly. Files are named for their section ("018 Raven solo 56.5s"), and each step for its time and cues.
  • Live/TimeLine/timelines/Teen Titans.tml: the timeline, every block at its time.
  • fixtures.ini and fixtures/SlimPAR 56 (7CH).txt: the venue's 13 SlimPAR 56 lights as Quan set them up (addresses 1, 33, 65… 385).
  • 3DView/fixtures.ini: where each light hangs in the 3D view.
  • Live/music.mp3: the song; the script makes a WAV copy so ShowXpress can draw its waveform.
